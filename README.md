# تایپینگ انیمیشن ساز ✨

یک ابزار حرفه‌ای و زیبا برای ساخت انیمیشن‌های تایپینگ فارسی با قابلیت‌های پیشرفته.

## 🎯 ویژگی‌ها

### ویژگی‌های اصلی:
- ✅ **انیمیشن تایپینگ روان** با قابلیت تنظیم سرعت
- ✅ **نشانگر چشمک‌زن (Cursor)** با قابلیت تغییر رنگ
- ✅ **نوار پیشرفت** نمایش درصد تکمیل انیمیشن
- ✅ **قالب‌های آماده** (خوش‌آمدگویی، کدنویسی، شعر، تبلیغاتی)
- ✅ **صدای تایپ** با استفاده از Web Audio API
- ✅ **آپلود فونت شخصی** (TTF, OTF, WOFF, WOFF2)
- ✅ **تنظیمات کامل** (رنگ متن، رنگ پس‌زمینه، اندازه فونت، ابعاد ناحیه)
- ✅ **ذخیره به صورت HTML** برای استفاده مستقل
- ✅ **اشتراک‌گذاری با لینک** (ذخیره تنظیمات در URL)

### ویژگی‌های فنی:
- 🚀 بهینه‌سازی عملکرد با استفاده از DOM manipulation به جای innerHTML
- 📱 طراحی واکنش‌گرا (Responsive)
- 🎨 رابط کاربری مدرن با گرادینت‌های زیبا
- 🔧 بدون نیاز به کتابخانه‌های خارجی

## 🚀 شروع سریع

1. فایل `index.html` را در مرورگر خود باز کنید
2. متن مورد نظر خود را وارد کنید یا از قالب‌های آماده استفاده کنید
3. تنظیمات دلخواه را اعمال کنید
4. دکمه "▶ شروع انیمیشن" را بزنید

## 📖 راهنمای استفاده

### استفاده از قالب‌های آماده
روی یکی از دکمه‌های قالب کلیک کنید تا متن نمونه بارگذاری شود:
- 🎉 **خوش‌آمدگویی**: متن خوش‌آمدگویی برای وبسایت
- 💻 **کد نویسی**: نمونه کد برنامه‌نویسی
- 📜 **شعر**: اشعار فارسی کلاسیک
- 📢 **تبلیغاتی**: متن‌های تبلیغاتی و promotional

### تنظیمات قابل تغییر:
- **فونت**: انتخاب از فونت‌های پیش‌فرض یا آپلود فونت شخصی
- **اندازه فونت**: 12 تا 72 پیکسل
- **سرعت تایپ**: 20 تا 500 میلی‌ثانیه
- **رنگ متن**: انتخابگر رنگ
- **رنگ پس‌زمینه**: انتخابگر رنگ
- **رنگ نشانگر**: انتخابگر رنگ برای cursor
- **ابعاد ناحیه**: عرض و ارتفاع قابل تنظیم

### صدا
با فعال کردن گزینه "🔊 پخش صدای تایپ"، صدای شبیه‌سازی شده تایپ پخش می‌شود.

### ذخیره و اشتراک‌گذاری

#### ذخیره به صورت HTML
با کلیک روی "💾 ذخیره به صورت HTML"، یک فایل HTML مستقل دانلود می‌شود که شامل تمام تنظیمات و انیمیشن شماست.

#### کپی لینک
با کلیک روی "🔗 کپی لینک"، یک URL با تمام تنظیمات شما در کلیپ‌بورد کپی می‌شود که می‌توانید آن را با دیگران به اشتراک بگذارید.

## 🛠️ توسعه

### ساختار پروژه:
```
/workspace
├── index.html      # فایل اصلی پروژه (HTML + CSS + JS)
└── README.md       # مستندات پروژه
```

### افزودن قابلیت‌های جدید:
1. توابع جدید را به بخش `<script>` اضافه کنید
2. استایل‌های جدید را به بخش `<style>` اضافه کنید
3. المان‌های UI را به HTML اضافه کنید

## 🎨 سفارشی‌سازی

### تغییر تم رنگی:
در بخش CSS، گرادینت‌های زیر را تغییر دهید:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### افزودن قالب جدید:
در بخش JavaScript، به آبجکت `templates` اضافه کنید:
```javascript
const templates = {
    // ...
    newTemplate: `متن قالب جدید`
};
```
